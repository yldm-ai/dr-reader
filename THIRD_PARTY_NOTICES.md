Preserve their license texts when distributing compiled artifacts. The `scripts/package.ps1` script collects those texts into the portable output.

calibre was read as a reference for EPUB splitting behavior; its GPLv3 code is not included or executed. Neat Reader and Starrea were inspected locally as layout references; their assets and code are not included. MSIME-Windows was inspected for component structure and native caption behavior; this project does not link to it or copy its source.

The welcome EPUB is original demonstration content generated by `scripts/make_sample.py`. Interface icons are Material Symbols Rounded paths inlined by `scripts/material-icons.ts`; the settings and author icons use the system Segoe Fluent Icons font, which is not redistributed. The welcome cover is defined in this project. No icons or assets are extracted from the reference applications.

The opening animation in `web/book-opening.ts` independently recreates the visual behavior of the user-supplied `MyKeymap/examples/SoundControlAnimation/main.cpp` using Canvas 2D. It preserves the five colors, seeded dash pattern, circle geometry and timing profiles; it does not include or link the reference application's native DirectX window implementation.

The optional layered book-opening scene is independently implemented with DOM elements and the Web Animations API, inspired by missarray's “Book opening animation (pure css)”: https://codepen.io/missarray/pen/oQmgzW. It recreates the orange cover, cream pages and staggered opening, then fades the opaque loading overlay as soon as the reading document is ready. No CodePen scripts, fonts or remote assets are loaded at runtime.
