# Third-party components

Dependencies are downloaded at configure time and are not copied from the local reference applications.

| Component | Pinned version | License / upstream |
| --- | --- | --- |
| pugixml | 1.15 | MIT — https://github.com/zeux/pugixml |
| nlohmann/json | 3.12.0 | MIT — https://github.com/nlohmann/json |
| miniz | 3.0.2 | MIT — https://github.com/richgel999/miniz |
| SQLite | 3.53.4 amalgamation | Public domain — https://www.sqlite.org/copyright.html |
| Microsoft.Web.WebView2 SDK | 1.0.2903.40 | Microsoft SDK license — https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.2903.40 |

Preserve their license texts when distributing compiled artifacts. The `scripts/package.ps1` script collects those texts into the portable output.

calibre was read as a reference for EPUB splitting behavior; its GPLv3 code is not included or executed. Neat Reader and Starrea were inspected locally as layout references; their assets and code are not included. MSIME-Windows was inspected for component structure and native caption behavior; this project does not link to it or copy its source.

The welcome EPUB is original demonstration content generated by `scripts/make_sample.py`. SVG icons and the welcome cover are defined in this project rather than extracted from the reference applications.
