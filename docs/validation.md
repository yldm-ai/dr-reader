# 初版验证

验证环境：Windows、本机 Visual Studio 2026 x64 工具链，Release 构建。

## 自动测试

`ctest --test-dir build -C Release --output-on-failure`：C++ 引擎集成测试，测试内部动态生成 EPUB 与 ZIP 夹具。

- 相对 URI、百分号解码、越界路径拒绝。
- 嵌套 DOM 分页、大小预算拆分、中文文件名、祖先 ID 唯一归属、head 保留与 XML 有效性。
- 内联、嵌入样式表及直接链接样式表的分页规则与后代选择器。
- EPUB 元数据、spine、目录和跨分段锚点链接修复。
- 重复导入、重新创建书库对象后的阅读进度、书签添加/移除、中文检索。
- ZIP 路径逃逸拒绝、解压大小限制、脚本与事件属性清理。

前端通过 Node 语法检查；C++ 使用项目的 clang-format 风格，前端通过 Prettier 格式化。

## 本机真实 EPUB 导入

通过无界面 `dr-epub` 工具导入本机已有四本书，生成到隔离测试目录 `build/real-books`；没有把书籍打包进项目，也没有修改原始 EPUB。

| 样本 | 输出章节数 | 目录项 | 初次导入耗时（本机） |
| --- | ---: | ---: | ---: |
| 中英对照圣经 | 1192 | 1190 | 约 2.4 秒 |
| 作文选集 | 13 | 476 | 约 0.2 秒 |
| 庄子 | 40 | 42 | 约 0.2 秒 |
| 摩登爱情合集 | 104 | 97 | 约 0.3 秒 |

耗时包含本机文件读取、解包、XML 处理、XHTML 拆分、目录映射与缓存写入。它是一次本机验证记录，不是通用性能保证。导入成功不代表每一页的排版都已人工核对。

## 桌面交互

实际启动 WebView2 桌面程序，观察书架、SVG 封面、目录、原创示例正文和阅读设置；确认左右翻页会改变显示内容、页码和进度。通过设置从系统标题栏切换至 C++ Direct2D 自绘标题栏，并检查标题栏实际绘制；关闭后重新打开，确认排版设置和继续阅读进度恢复。便携目录单独启动成功。

另外将本机《庄子》通过相同 C++ 引擎导入到实际书库，在桌面端核对封面、层级目录、目录到“逍遥游”的跳转、正文与原书样式表。文件选择器能正常弹出；自动化工具未能稳定定位其文件名控件，因此文件选择提交没有纳入自动交互验收。

完整 CSS 级联、损坏 HTML 修复、字体混淆、固定版式、复杂表格跨页和 RTL/竖排仍不在本次验收范围内，见 README 当前边界。
