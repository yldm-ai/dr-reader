# 当前验证

验证环境：Windows、本机 Visual Studio 2026 x64 工具链，Release 构建。

## 自动测试

`ctest --test-dir build -C Release --output-on-failure`：C++ 引擎集成测试，测试内部动态生成 EPUB 与 ZIP 夹具。

- 相对 URI、百分号解码、越界路径拒绝。
- 嵌套 DOM 分页、大小预算拆分、中文文件名、祖先 ID 唯一归属、head 保留与 XML 有效性。
- 内联、嵌入样式表及直接链接样式表的分页规则与后代选择器。
- EPUB 元数据、spine、目录和跨分段锚点链接修复。
- 重复导入、重新创建书库对象后的阅读进度、书签添加/移除、中文检索。
- SQLite 标注插入、修改、重新打开数据库后的持久化与删除。
- 版本 2 设置默认值、分组更新、旧扁平设置迁移、非法枚举拒绝和查词 URL 百分号编码。
- ZIP 路径逃逸拒绝、解压大小限制、脚本与事件属性清理。

安装 Node.js 22.18 或更新版本时，CTest 同时运行滚轮导航和前端状态回归；也可执行 `pnpm test`。覆盖单次一页、连续输入串行执行、反向翻页、滚动/缩放手势、过期请求取消、章节边界、字体值与标签、阅读设置比较以及章节 LRU 缓存。

`pnpm test:browser` 使用系统 Edge 验证不同宽度的正文分页、标注的共享文本扫描、选词与查词交互、下拉框键盘操作、字体搜索与保存恢复、滑块批量更新、窄窗口边界，以及实际 Vite 生产包的书架、开书、分页和字体选择。截图覆盖明亮、纸张和夜间主题，输出位于 `build/browser-tests/`。测试使用专用消息桥夹具，不访问用户数据。

视觉回归额外通过实际设置操作切换主题，检查深色页面、侧栏和浮层为中性灰，正文与排版预览使用相同的阅读主题，并验证应用主题不会覆盖独立的正文主题；深色正文、辅助文字和主按钮文字的对比度至少为 4.5:1。书架、阅读页、应用设置及下拉菜单保存独立截图供检查。

构建独立执行 TypeScript 严格类型检查；现有 JavaScript 阅读器逐步迁移，C++ 继续使用项目的 clang-format 风格。

翻页回归检查平移的旧页与新页同步移动完整一页、两帧的实际滚动位置、标注随快照保留、正反向 180 度翻页、跨章节等待新文档、取消后只提交一次并清理临时 iframe。中间帧截图保存到 `build/browser-tests/slide-forward.png`、`turn-forward.png` 和 `turn-backward.png`。

沉浸回归通过生产包的实际设置入口隐藏全部阅读控件，验证正文 iframe 占满应用可用区域、四边留白独立生效、左右点击各翻一页、取消文字选择不翻页、F8 和中央点击恢复设置、全屏消息及 Esc 退出顺序。C++ 测试覆盖新设置校验和旧留白迁移；原生验证在独立数据目录中检查了 D2D 和云母两种外壳的 Alt+Enter 全屏、恢复窗口位置尺寸和标题栏。

## 本机真实 EPUB 导入

通过无界面 `dr-epub` 工具导入本机已有四本书，生成到隔离测试目录 `build/real-books`；没有把书籍打包进项目，也没有修改原始 EPUB。

| 样本 | 输出章节数 | 目录项 | 初次导入耗时（本机） |
| --- | ---: | ---: | ---: |
| 中英对照圣经 | 1192 | 1190 | 约 2.4 秒 |
| 作文选集 | 13 | 476 | 约 0.2 秒 |
| 庄子 | 40 | 42 | 约 0.2 秒 |
| 摩登爱情合集 | 104 | 97 | 约 0.3 秒 |

耗时包含本机文件读取、解包、XML 处理、XHTML 拆分、目录映射与缓存写入。它是一次本机验证记录，不是通用性能保证。导入成功不代表每一页的排版都已人工核对。

## 桌面交互

实际启动 WebView2 桌面程序，观察书架、SVG 封面、目录、原创示例正文和阅读设置；确认左右翻页会改变显示内容、页码和进度。通过设置从系统标题栏切换至 C++ Direct2D 自绘标题栏，并检查标题栏实际绘制；关闭后重新打开，确认排版设置和继续阅读进度恢复。便携目录单独启动成功。

应用设置使用独立全页，阅读设置使用侧边面板。阅读页需要核对选区菜单、五色高亮、下划线、笔记编辑与删除、标注列表、自定义查词网站、开书动画以及滚动/分页两种翻页动画。Direct2D 标题栏高度由 `AdjustWindowRectExForDpi` 按系统 caption 指标计算，切换外壳时需在 100%/125%/150% 缩放下与原生标题栏对照。

另外将本机《庄子》通过相同 C++ 引擎导入到实际书库，在桌面端核对封面、层级目录、目录到“逍遥游”的跳转、正文与原书样式表。文件选择器能正常弹出；自动化工具未能稳定定位其文件名控件，因此文件选择提交没有纳入自动交互验收。

完整 CSS 级联、损坏 HTML 修复、字体混淆、固定版式、复杂表格跨页和 RTL/竖排仍不在本次验收范围内，见 README 当前边界。


## 阅读方式与设置页面回归

- “阅读设置 → 阅读方式”可切换“左右翻页 / 上下滚动”，工具栏只保留阅读设置入口；新书库默认分页，已保存的滚动偏好仍然保留。
- 《庄子》长章节可显示多页，点击下一页会更新页码；目录、搜索结果及笔记跳转在分页模式下对齐到整页。
- 选择文字后按 Esc：菜单关闭并清除选择，仍停留在阅读页。滚动正文、点击正文空白或工具栏、切章、打开设置和窗口失焦均收起菜单。
- 书架应用设置为独立全页，分类导航可以跳转，返回按钮和 Esc 返回来源页面；书内阅读设置仍为侧边面板。
- 从阅读页打开应用设置再返回时，保留章节及阅读位置；应用设置不展示阅读设置控件。

- 分页正文滚轮向下一格前进一页、向上一格后退一页；连续滚动时翻页依次完成。滚动模式、阅读设置面板与目录的滚轮保留正常滚动行为。


## 窗口与工具栏图标

- 系统标题栏使用内嵌书本应用图标，窗口小图标和任务切换大图标按 DPI 加载；跨屏 DPI 变化时更新，关闭窗口时释放实例图标。
- `resources/dr-reader.ico` 包含 16/20/24/32/40/48/64/128/256 像素图层，`tools/generate_icon.ps1` 可重新生成 ICO 与 SVG 源图。
- 设置齿轮路径完整位于 SVG 的 24×24 画布内，检查书架与阅读工具栏的齿轮均无边缘裁切。


## 界面字体与字号

- 界面优先使用微软雅黑，依次回退至微软雅黑 UI、Noto Sans SC、Noto Sans CJK SC、Segoe UI 和系统无衬线字体；自绘标题栏使用相同的可用字体顺序。
- 统一字号层级：辅助说明 12–13px、常用标签与控件 14px、导航 15px、分组标题 16px、面板标题 20px。应用设置分类及分组标题使用 500 字重，常用标签、正文和说明保留 400 常规字重。
- 已在明亮及夜间主题检查应用设置、书架、目录和阅读设置，确认字体加大后控件无挤压；阅读设置面板使用可伸缩内容区，底部内容仍可滚动访问。
- EPUB 正文继续使用阅读设置中的字体和字号；选择默认无衬线字体时优先微软雅黑。

- Direct2D 标题栏使用 Segoe Fluent Icons 的 ChromeMinimize（E921）、ChromeMaximize（E922）、ChromeRestore（E923）和 ChromeClose（E8BB），字形来自[微软官方定义](https://learn.microsoft.com/en-us/windows/apps/design/iconography/segoe-fluent-icons-font)。最大化后切换还原图标，并保留关闭按钮的红色悬停效果；没有 Fluent 字体时回退至 Segoe MDL2 Assets。


## 末页留白与设置回顶回归

- 修复 CSS 分栏末页的滚动范围缺少尾部留白：章节末页现在保留完整页面宽度，避免 `scrollTo` 被浏览器钳制后把文字推到右边缘。分栏宽度与翻页步长一致，覆盖小数像素窗口宽度。
- `tests/reader_layout.html` 通过本地 HTTP 服务打开后应显示 PASS。它直接使用阅读器的样式与分页测量，在 760 / 731.5 / 540px 三种宽度验证末页位置、文字左右边界、重复重排页数、容器字体继承和滚动模式关闭分页占位。
- 本轮已使用 Edge 无头模式运行上述真实布局测试，三种宽度全部通过；另以本机《流俗地》的对应章节副本验收，副本仅位于忽略的 build 目录。
- 应用设置是应用内不可移动的模态面板：左侧外观 / 选词与查词 / 关于三个分组，右侧“应用设置”标题固定，仅分组内容滚动，导航随滚动高亮当前分组；右上角关闭按钮、Esc 或点击面板外关闭。
- 平移与覆盖在章内翻页时使用常驻副本层（`page-strip.ts`）：版式、章节或标注变化后在后台载入 4 份当前章节副本，翻页只改变副本的滚动位置并在同一帧开始动画（实测点击到首个移动帧 21–50ms），曲线为强减速的 `cubic-bezier(0.22, 1, 0.36, 1)`。点击或按键再次翻页从各页当前位置重定目标，不排队、不跳变；覆盖按阅读顺序叠放，向后翻当前页移走、向前翻上一页从左侧盖回。跨章节翻页仍走快照路径。
- 副本尚未预载时，首次章内覆盖 / 平移翻页会立即准备副本，成功后仍使用可打断的常驻层；预载期间取消不会提交旧翻页。滚轮每个有效事件累计一页，逐页等待可见动画结束后再播放下一页；积压越多动画越快，最高 10 倍，队列清空后恢复正常速度。跨章前排队及章节加载期间收到的滚轮动作按顺序延续到新章节；手动跳转或退出阅读会取消旧队列。
- 高亮默认使用 Notion 背景色（深色阅读主题用其深色值，下划线用对应文字色），调色板保存最近 5 种颜色；自定义颜色放到首位并挤掉末位。标注数据库升级到 schema 2，一次性重建 `annotations` 表以允许 `#rrggbb`，原有行原样保留。
- 全书页码按当前排版统计：读过的章节用实测页数，其余按 C++ 搜索文本的字数和实测密度估算并显示“约”。
- 侧边栏、阅读设置、应用设置和下拉列表使用自绘叠加滚动条（`scrollbar.ts`）：轨道距上下边缘 6px，滑块圆角 1px，滚动到两端也不越过圆角；其余原生滚动条圆角同为 1px。
- 按钮悬浮提示全部自绘（`tooltip.ts`），参照 MSIME 设置窗口：停留 500ms 后淡入并下移 2px，居中于控件下方 2px、贴边时收回窗口内；`title` 属性会被接管，不出现系统提示。Direct2D 标题栏的最小化 / 最大化 / 关闭按钮由原生窗口计时，提示在其正下方的网页层绘制；悬停最大化时仍保留 Windows 11 贴靠布局浮窗。
- Direct2D 标题栏文字优先使用微软雅黑，正常字重（400）、12 DIP 字号，左边距保持 10 DIP。


## 标注删除、目录悬停与查词窗口

- 点击已有下划线或高亮时，选区菜单提供“删除标注”，直接删除 SQLite 中的整条标注并刷新正文和笔记列表；已有下划线操作显示按下状态。重新选中与标注相同的范围仍能识别已有标注。
- 目录区域滚动后停用悬停背景，鼠标实际移动时再恢复；当前章节的选中背景保留，书签、搜索与笔记列表遵循同样的悬停规则。
- 查词网站选择窗口支持右上角关闭、点击外部空白和 Esc 取消；内部空白不误关闭，取消不会打开查词网站，正常选择网站仍返回所选项。
- `tests/reader_interactions.html` 通过本地 HTTP 服务运行，使用生产菜单和交互代码以及隔离的内存桥接数据，验证删除请求、菜单状态、各关闭路径和滚动后的悬停恢复。本轮 Edge 无头运行显示 PASS；桌面窗口另确认已有下划线的删除入口与弹框外部点击关闭。
